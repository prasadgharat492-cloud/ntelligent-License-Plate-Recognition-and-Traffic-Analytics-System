## ⚡ Features
- 🎥 **Real-time License Plate Scanner** using OpenCV & EasyOCR.  
- 📊 **Excel Logging** of car entries with first seen & last seen times.  
- 📈 **Analytics Dashboard**:
  - Per Hour Analysis
  - Last 7 Days Analysis
  - Unique Car Count  
- 🤖 **Machine Learning (Peak Hour Forecasting)**:
  - Uses historical data to predict **next day's busiest hour**.
